smriti · memory an agent can trust

An AI assistant at a garment company, Kaveri, remembers what each person tells it. A changed fact replaces the old one instead of piling up next to it, old answers stay queryable by date, people only see their own, their team's and the company's memories, and only HR can change company-wide facts. The memory layer from the repo runs here as Go WebAssembly.

Source and README (the full version stores memories in Postgres with pgvector; this page keeps them in memory with the same rules. The facts are pulled out by the repo's rule-based extractor; the README covers the LLM extractor.)
